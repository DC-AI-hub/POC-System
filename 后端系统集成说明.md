## 系统架构

### 技术栈
- **前端**: Next.js 15.2.4 + React 19 + TypeScript (端口5137)
- **后端**: 需要实现的API服务 (建议Node.js/Python/Java)
- **数据库**: PostgreSQL 15+
- **缓存**: Redis 7+
- **文件存储**: 本地存储/云存储
- **消息队列**: Redis/RabbitMQ (可选)

## API接口规范

### 基础URL
```
开发环境: http://localhost:8000/api
生产环境: https://111.231.53.25/api
```

### 通用响应格式
```typescript
interface ApiResponse<T = any> {
  success: boolean;
  data?: T;
  error?: {
    code: string;
    message: string;
    details?: any;
  };
  meta?: {
    requestId: string;
    timestamp: string;
    version: string;
  };
}

interface PaginatedResponse<T> extends ApiResponse<T[]> {
  pagination: {
    page: number;
    limit: number;
    total: number;
    totalPages: number;
  };
}
```

### HTTP状态码规范
```
200 OK - 请求成功
201 Created - 资源创建成功
204 No Content - 请求成功，无返回内容
400 Bad Request - 请求参数错误
401 Unauthorized - 未认证
403 Forbidden - 无权限
404 Not Found - 资源不存在
409 Conflict - 资源冲突
422 Unprocessable Entity - 数据验证失败
429 Too Many Requests - 请求过于频繁
500 Internal Server Error - 服务器内部错误
503 Service Unavailable - 服务不可用
```

### 请求头规范
```http
Content-Type: application/json
Authorization: Bearer <token>
X-Request-ID: <uuid>
X-Client-Version: 1.0.0
Accept-Language: zh-CN,en-US
```

## 性能要求

### 响应时间要求
- API响应时间: < 500ms (95th percentile)
- 数据库查询: < 100ms (平均)
- 外部系统集成: < 5s (超时)
- 文件上传: < 30s (50MB以内)

### 并发要求
- 支持并发用户: 1000+
- API QPS: 500+
- 数据库连接池: 50-100

### API测试脚本
```bash
#!/bin/bash
# API测试脚本

BASE_URL="http://localhost:8000/api"
TOKEN=""

# 登录获取Token
login() {
  response=$(curl -s -X POST "$BASE_URL/auth/login" \
    -H "Content-Type: application/json" \
    -d '{"username":"admin","password":"admin123"}')
  
  TOKEN=$(echo $response | jq -r '.data.token')
  echo "Token: $TOKEN"
}

# 测试集成配置
test_integrations() {
  curl -X GET "$BASE_URL/integrations" \
    -H "Authorization: Bearer $TOKEN" \
    -H "Content-Type: application/json"
}

login
test_integrations
```
