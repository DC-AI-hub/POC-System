# 审批管理模块优化总结

## 优化概述

根据用户需求，审批管理模块已完成全面优化升级，实现了灵活审批、多审批人模式、动态运行时分配、委托审批等高级功能，并大幅增加了示例数据，确保每次筛选都有足够的数据样本可查看。

## 主要优化内容

### 1. 灵活审批模式实现

#### 1.1 新增5种审批模式
- **顺序审批 (Sequential)**: 传统串行审批，适用于层级审批
- **并行审批-全部通过 (Parallel)**: 所有审批人必须同意，适用于重要决策
- **并行审批-任一通过 (Any One)**: 任意一人同意即可，适用于多人有权限的场景
- **多数通过 (Majority)**: 超过半数同意即通过，适用于委员会决策
- **权重审批 (Weighted)**: 基于权重累计的审批，适用于不同职级权重不同的场景

#### 1.2 审批组配置
- **技术部主管组**: 任一通过模式，包含技术总监、项目经理、架构师
- **财务审批委员会**: 多数通过模式，包含财务总监、会计经理、预算经理
- **合规审核组**: 并行全部模式，包含合规专员、法务顾问
- **销售部门组**: 权重审批模式，不同职级有不同权重

### 2. 动态分配规则

#### 2.1 智能分配规则
- **金额规则**: 大额费用(>50,000元)自动分配给财务审批委员会
- **部门规则**: 技术部/IT部/研发部申请分配给技术部主管组
- **类型规则**: 差旅费用自动进入合规审核流程
- **自定义规则**: 支持复杂条件表达式，如销售部差旅费特殊处理

#### 2.2 规则优先级
- 支持规则优先级设置，确保规则执行顺序
- 高优先级规则优先匹配和执行

### 3. 委托审批功能

#### 3.1 委托配置
- **张技术总监 → 李项目经理**: 出差期间委托，覆盖AA1和主管审批
- **陈财务总监 → 赵会计经理**: 年假期间委托，覆盖财务审批

#### 3.2 委托管理
- 支持委托时间范围设置
- 委托范围可配置（特定审批步骤）
- 委托原因记录和状态管理

### 6. 类型系统扩展

#### 6.1 新增类型定义
```typescript
// 灵活审批相关类型
export type ApproverType = 'user' | 'group' | 'role';
export type ApprovalMode = 'sequential' | 'parallel' | 'any_one' | 'majority' | 'weighted';
export type DynamicAssignmentCondition = 'amount_based' | 'department_based' | 'type_based' | 'custom_rule';

// 审批组配置
export interface ApprovalGroup {
  id: string;
  name: string;
  description: string;
  mode: ApprovalMode;
  approvers: ApproverDefinition[];
  passCondition?: {
    type: 'all' | 'any' | 'majority' | 'weighted';
    minWeight?: number;
    minCount?: number;
  };
  // ...其他配置
}

// 动态分配规则
export interface DynamicAssignmentRule {
  id: string;
  name: string;
  condition: DynamicAssignmentCondition;
  rules: {
    amountRange?: { min?: number; max?: number; };
    departments?: string[];
    types?: string[];
    customExpression?: string;
  };
  assignTo: { type: 'group' | 'user' | 'role'; id: string; };
  priority: number;
}

// 委托配置
export interface DelegationConfig {
  id: string;
  delegatorId: string;
  delegatorName: string;
  delegateeId: string;
  delegateeName: string;
  startDate: Date;
  endDate: Date;
  scopes: string[];
  isActive: boolean;
  reason?: string;
}
```

#### 6.2 扩展原有类型
- `ApprovalItem`: 增加审批组、审批模式、进度信息、委托状态等字段
- `ApprovalFilters`: 增加审批模式、委托状态、动态分配等过滤条件
- `ApprovalStats`: 增加灵活审批相关的统计信息
- `UseApprovalManagementReturn`: 增加审批组、动态规则、委托管理等功能
