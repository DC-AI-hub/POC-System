# 审批管理模块 - 灵活审批功能指南

## 功能概述

审批管理模块已全面升级，支持灵活的审批流程配置，包括多审批人模式、动态运行时分配、委托审批等高级功能。

## 主要功能特性

### 1. 灵活审批模式

#### 1.1 顺序审批 (Sequential)
- **描述**: 传统的串行审批模式，一个接一个进行审批
- **适用场景**: 需要按层级依次审批的场景
- **图标**: 🔀 GitBranch
- **示例**: 申请人 → 直属主管 → 部门负责人 → 财务

#### 1.2 并行审批 - 全部通过 (Parallel - All)
- **描述**: 多人同时审批，需要所有人都同意才能通过
- **适用场景**: 重要决策需要多方一致同意
- **图标**: 👥 Users
- **示例**: 大额采购需要财务总监、技术总监、CEO同时同意

#### 1.3 并行审批 - 任一通过 (Any One)
- **描述**: 多人同时审批，任意一人同意即可通过
- **适用场景**: 多个有权限的人员，任一人可做决定
- **图标**: ✅ UserCheck
- **示例**: 部门内多个主管，任一人可审批日常费用

#### 1.4 多数通过 (Majority)
- **描述**: 多人审批，超过半数同意即可通过
- **适用场景**: 委员会决策，民主投票
- **图标**: 👥 Users
- **示例**: 5人委员会，3人以上同意即通过

#### 1.5 权重审批 (Weighted)
- **描述**: 基于权重的审批，总权重达到阈值即通过
- **适用场景**: 不同职级有不同决策权重
- **图标**: ⚡ Zap
- **示例**: CEO权重20，总监权重15，经理权重10，需要权重25以上

### 2. 审批组配置

#### 2.1 审批组管理
- **技术部主管组**: 任一人审批模式，包含技术总监、项目经理、架构师
- **财务审批委员会**: 多数通过模式，包含财务总监、会计经理、预算经理
- **合规审核组**: 并行全部模式，包含合规专员、法务顾问
- **销售部门组**: 权重审批模式，销售总监权重20，区域经理权重15

#### 2.2 组配置属性
- **审批模式**: sequential/parallel/any_one/majority/weighted
- **通过条件**: 最少人数、最小权重、全部/任一
- **超时设置**: 自动超时时间（小时）
- **委托设置**: 是否允许委托、自动委托配置

### 3. 动态分配规则

#### 3.1 基于金额的分配
- **规则**: 大额费用（>50,000元）自动分配给财务审批委员会
- **优先级**: 1（最高）

#### 3.2 基于部门的分配
- **规则**: 技术部、IT部、研发部的申请分配给技术部主管组
- **优先级**: 2

#### 3.3 基于类型的分配
- **规则**: 差旅费用申请自动进入合规审核流程
- **优先级**: 3

#### 3.4 自定义规则表达式
- **规则**: 销售部差旅费超过10,000元的特殊处理
- **表达式**: `department === "销售部" && type === "travel" && amount > 10000`
- **分配**: 销售部门组权重审批

### 4. 委托审批功能

#### 4.1 委托配置
- **张技术总监 → 李项目经理**: 出差期间委托，覆盖AA1和主管审批
- **陈财务总监 → 赵会计经理**: 年假期间委托，覆盖财务审批

#### 4.2 委托属性
- **委托人/被委托人**: 明确的委托关系
- **生效时间**: 开始和结束日期
- **委托范围**: 特定的审批步骤
- **委托原因**: 出差、请假、培训等
- **是否有效**: 当前状态

### 5. 审批进度跟踪

#### 5.1 进度显示
- **已审批/总数**: 当前已完成的审批人数
- **需要数量**: 根据审批模式计算的最少需要人数
- **权重进度**: 权重审批模式下的权重累计

#### 5.2 状态标识
- **委托标识**: 🔄 显示委托审批
- **动态分配标识**: ⚡ 显示自动分配
- **审批模式**: 不同模式的图标和颜色标识

## 过滤和搜索功能

### 1. 基础过滤
- **申请类型**: 日常费用、差旅费用
- **状态**: 待审批、审批中、已通过、已拒绝
- **优先级**: 高、中、低

### 2. 灵活审批过滤
- **审批模式**: 按具体审批模式筛选
- **委托状态**: 筛选委托审批的申请
- **动态分配**: 筛选自动分配的申请

### 3. 高级搜索
- **关键词搜索**: 申请人、标题、申请单号、部门
- **金额范围**: 按金额区间筛选
- **日期范围**: 按提交时间筛选

- **活跃委托数**: 当前生效的委托配置数
