# 港交所POC系统 - 系统配置管理使用指南

## 📋 功能概述

系统配置管理是港交所POC系统的核心管理模块，提供完整的系统配置、角色权限、费用科目和工作流程管理功能。该模块确保系统的灵活性、安全性和可维护性。

## 🎯 核心功能

### 1. 角色管理
- **角色创建**: 创建自定义角色，设置权限层级
- **角色编辑**: 修改角色信息和权限配置
- **角色删除**: 删除非内置角色（内置角色受保护）
- **权限层级**: 5级权限体系（1-最高权限，5-最低权限）

### 2. 权限矩阵
- **可视化配置**: 直观的权限矩阵界面
- **模块权限**: 按功能模块配置权限
- **操作权限**: 细粒度的CRUD操作权限
- **批量设置**: 支持批量权限配置

### 3. 费用科目管理
- **树形结构**: 支持多级科目分类
- **预算控制**: 设置科目预算限制
- **审批配置**: 配置科目是否需要审批
- **拖拽排序**: 支持科目顺序调整

### 4. 工作流配置
- **流程设计**: 可视化工作流设计器
- **节点配置**: 配置审批节点和条件
- **角色绑定**: 绑定审批角色和时限
- **版本管理**: 工作流版本控制

### 5. 系统参数
- **分类管理**: 按类别管理系统参数
- **在线编辑**: 支持在线修改参数值
- **类型支持**: 支持字符串、数字、布尔等类型
- **验证规则**: 参数值验证和约束

### 6. 配置管理
- **导入导出**: 支持配置的导入导出
- **版本控制**: 配置版本管理和回滚
- **变更日志**: 完整的配置变更记录
- **配置验证**: 导入前的配置验证

## 🚀 快速开始

### 访问系统配置
1. 登录港交所POC系统
2. 在左侧导航栏点击"系统配置管理"
3. 进入系统配置管理界面

### 界面布局
- **顶部标题栏**: 显示当前模块信息
- **Tab导航**: 6个主要功能模块
- **主内容区**: 当前模块的详细功能
- **操作按钮**: 新增、编辑、删除等操作

## 📖 详细功能指南

### 角色管理

#### 创建新角色
1. 点击"角色管理"标签页
2. 点击"新建角色"按钮
3. 填写角色信息：
   - **角色名称**: 角色的显示名称
   - **角色代码**: 系统内部使用的唯一标识
   - **描述**: 角色的详细说明
   - **权限层级**: 选择1-5级权限
   - **启用状态**: 是否启用该角色
4. 点击"创建"按钮保存

#### 编辑角色
1. 在角色列表中找到目标角色
2. 点击"编辑"按钮
3. 修改角色信息
4. 点击"保存"确认修改

#### 删除角色
1. 在角色列表中找到目标角色
2. 点击"删除"按钮
3. 确认删除操作
4. **注意**: 内置角色无法删除

### 权限矩阵配置

#### 选择角色
1. 点击"权限矩阵"标签页
2. 在下拉菜单中选择要配置的角色
3. 系统显示该角色的权限配置界面

#### 配置权限
1. 按功能模块配置权限：
   - **费用管理**: 创建、查看、修改、删除、审批
   - **差旅管理**: 创建、查看、修改、删除、审批
   - **人员管理**: 创建、查看、修改、删除
   - **审批管理**: 查看、审批、拒绝、委托
   - **报表分析**: 查看、导出
   - **系统配置**: 查看、修改

2. 勾选相应的权限复选框
3. 点击"保存权限"按钮

#### 权限继承
- 高级别角色自动继承低级别权限
- 子角色可继承父角色的部分权限
- 支持权限覆盖和自定义

### 费用科目管理

#### 创建科目
1. 点击"费用科目"标签页
2. 点击"新建科目"按钮
3. 填写科目信息：
   - **科目名称**: 科目的显示名称
   - **科目代码**: 唯一的科目编码
   - **上级科目**: 选择父级科目（可选）
   - **预算限制**: 设置预算上限（可选）
   - **描述**: 科目的详细说明
   - **需要审批**: 是否需要审批流程
4. 点击"创建"按钮保存

#### 科目层级
- **一级科目**: 主要费用分类（如办公用品、差旅费用）
- **二级科目**: 细分类别（如文具用品、办公设备）
- **多级支持**: 支持多级科目嵌套

#### 科目操作
- **展开/折叠**: 点击箭头图标展开或折叠子科目
- **编辑科目**: 点击编辑按钮修改科目信息
- **删除科目**: 点击删除按钮移除科目
- **拖拽排序**: 拖拽调整科目显示顺序

### 工作流配置

#### 工作流类型
- **费用申请流程**: 日常费用申请的审批流程
- **差旅报销流程**: 差旅费用报销的审批流程
- **通用流程**: 其他业务流程

#### 创建工作流
1. 点击"工作流"标签页
2. 点击"新建工作流"按钮
3. 配置工作流信息：
   - **流程名称**: 工作流的显示名称
   - **流程代码**: 系统标识符
   - **流程类型**: 选择适用的业务类型
   - **描述**: 流程的详细说明
4. 设计流程节点和连线
5. 配置节点属性和条件
6. 保存工作流配置

#### 节点类型
- **开始节点**: 流程起始点
- **审批节点**: 需要人工审批的节点
- **条件节点**: 根据条件分支的节点
- **结束节点**: 流程结束点

#### 节点配置
- **节点名称**: 节点的显示名称
- **执行角色**: 可以执行该节点的角色
- **时间限制**: 节点处理的时限
- **必填字段**: 节点必须填写的字段
- **条件设置**: 节点的执行条件

### 系统参数设置

#### 参数分类
- **通用设置**: 系统标题、版本信息等
- **审批设置**: 审批超时时间、默认审批人等
- **通知设置**: 邮件通知、短信通知等

#### 修改参数
1. 点击"系统参数"标签页
2. 找到要修改的参数
3. 点击"编辑"按钮
4. 根据参数类型修改值：
   - **字符串**: 直接输入文本
   - **数字**: 输入数值
   - **布尔值**: 使用开关切换
5. 点击"保存"按钮确认

#### 参数验证
- 系统会自动验证参数值的有效性
- 不符合规则的参数值会显示错误提示
- 某些关键参数不允许修改

### 配置管理

#### 导出配置
1. 点击"配置管理"标签页
2. 点击"导出配置"按钮
3. 系统自动下载配置文件
4. 文件格式：JSON，包含所有配置信息

#### 导入配置
1. 准备配置文件（JSON格式）
2. 在导入区域粘贴配置内容
3. 系统自动验证配置格式
4. 验证通过后点击"导入配置"
5. 确认导入操作

#### 变更日志
- **操作记录**: 记录所有配置变更操作
- **操作人**: 显示执行操作的用户
- **操作时间**: 记录操作的具体时间
- **变更内容**: 显示变更前后的对比
- **操作类型**: 创建、更新、删除等

## 🔧 高级功能

### 批量操作
- **批量角色管理**: 批量创建、修改、删除角色
- **批量权限设置**: 批量配置多个角色的权限
- **批量科目导入**: 通过Excel批量导入费用科目
- **批量参数更新**: 批量修改系统参数

### 权限继承
- **角色继承**: 子角色可继承父角色权限
- **权限叠加**: 多个角色的权限可以叠加
- **权限覆盖**: 特定权限可以覆盖继承的权限

### 工作流引擎
- **条件分支**: 根据业务条件自动选择流程分支
- **并行审批**: 支持多个节点同时审批
- **委托审批**: 支持审批权限的临时委托
- **超时处理**: 自动处理审批超时情况

- **版本管理**: 每次配置变更都会创建新版本
- **版本对比**: 对比不同版本之间的差异

## ⚠️ 注意事项

### 安全考虑
1. **权限最小化原则**: 只授予必要的权限
2. **定期审查**: 定期检查和更新权限配置
3. **操作审计**: 所有操作都有完整的审计记录
4. **敏感操作确认**: 重要操作需要二次确认

### 操作限制
1. **内置角色保护**: 系统内置角色不能删除或修改核心属性
2. **权限依赖检查**: 删除角色前检查是否有用户依赖
3. **科目使用检查**: 删除科目前检查是否有业务数据使用
4. **工作流激活检查**: 修改工作流前检查是否有进行中的流程

### 最佳实践
1. **命名规范**: 使用清晰、一致的命名规范
2. **权限分级**: 合理设置权限层级，避免权限过于集中
3. **定期备份**: 定期导出配置进行备份
4. **测试验证**: 配置变更前在测试环境验证

## 🆘 常见问题

### Q: 如何创建新的用户角色？
A: 在"角色管理"页面点击"新建角色"，填写角色信息，设置权限层级，然后在"权限矩阵"页面配置具体权限。

### Q: 为什么某些角色无法删除？
A: 系统内置角色（如系统管理员、普通员工等）受到保护，无法删除。只能删除自定义创建的角色。

### Q: 如何设置费用科目的预算限制？
A: 在创建或编辑费用科目时，在"预算限制"字段输入金额上限。超过此限制的申请将需要特殊审批。

### Q: 工作流配置后如何生效？
A: 工作流配置保存后会立即生效，新的申请将使用新的工作流程。进行中的流程仍使用原有配置。

### Q: 如何备份和恢复系统配置？
A: 使用"配置管理"页面的导出功能备份配置，需要恢复时使用导入功能。建议定期备份重要配置。

### Q: 权限修改后多久生效？
A: 权限修改后立即生效，用户下次登录或刷新页面后即可看到权限变更。
